
# Movies Dataset EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Movies Dataset containing metadata for 45,466 movies.

## Dataset

Source: Kaggle

Dataset Name: Movies Dataset 45K Films with Budget and Revenue

Records: 45,466 movies

## Objectives

- Understand dataset structure
- Analyze missing values
- Detect duplicate records
- Explore categorical and numerical features
- Study revenue, budget, runtime and ratings
- Compare Pearson and Spearman correlation
- Create a new engineered feature

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Missingno
- SciPy

## Key Findings

- Revenue contains many zero values and extreme outliers.
- Most movies are not part of a collection.
- Missing values are concentrated in a few metadata columns.
- Runtime and revenue show weak Pearson correlation.
- Spearman correlation is higher than Pearson correlation.
- Most blockbuster movies have runtime between 80 and 200 minutes.
